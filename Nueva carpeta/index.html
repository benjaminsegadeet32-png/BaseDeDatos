1. DER (Diagramas Entidad-Relación) y Formas Normales

El DER es una herramienta gráfica que permite representar la información de un sistema y cómo se relaciona entre sí.

Hay 2 tipos de DER, Fisico y Logico:

Para tenerlo simple y memorable, el Fisico se enfoca en el "cómo" mientras el Logico se enfoca en el "qué".

Formas Normales (Normalización):

* 1FN Eliminar valores repetidos y definir clave primaria.

* 2FN Que todos los atributos dependan totalmente de la clave primaria.

* 3FN Eliminar dependencias transitivas.

Insertar Registros:

INSERT INTO, utilizado para agregar nuevos datos en una tabla existente.

INSERT INTO alumnos (id, nombre, apellido, edad)
VALUES (1, 'Juan', 'Pérez', 17);
Consultas Básicas:

SELECT, FROM y WHERE para consultar y filtrar información especifica dentro de las tablas.

SELECT nombre, apellido
FROM alumnos
WHERE edad >= 18;
Ordenamiento y Agrupación:

ORDER BY: Ordena el resultado de forma ascendente (ASC) o descendente (DESC).

GROUP BY: Agrupa filas que tienen los mismos valores en filas de resumen (ej. usar con COUNT, AVG, SUM).

SELECT curso, COUNT(*) AS total_alumnos
FROM alumnos
GROUP BY curso
ORDER BY total_alumnos DESC;
Relaciones y Filtros Agrupados:

INNER JOIN: Combina filas de dos o más tablas en base a una columna relacionada.

HAVING: Condición que filtra los resultados pero solo después de un GROUP BY (como reemplazo de WHERE ya que WHERE no se puede usar con funciones de agregación).

SELECT cursos.nombre, COUNT(alumnos.id) AS cantidad
FROM alumnos
INNER JOIN cursos ON alumnos.id_curso = cursos.id
GROUP BY cursos.nombre
HAVING cantidad > 10;
